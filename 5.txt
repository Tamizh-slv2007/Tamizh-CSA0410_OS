EXPERIMENT 5 — Priority Scheduling (Highest Priority Next, Non-Preemptive)
======================================================================

AIM:
To construct a scheduling program that selects the waiting process with the highest priority to execute next.

ALGORITHM:
1. Start the program.
2. Read `n` processes with burst time and priority (lower number = higher priority).
3. Sort processes in ascending order of priority.
4. Compute waiting time and turnaround time in that order.
5. Compute and display average waiting and turnaround times.
6. Stop.

PROGRAM (copy-paste ready):
----------------------------------------------------------------------
#include <stdio.h>

struct Process {
    int id, bt, pr, wt, tat;
};

int main() {
    int n, i, j;
    struct Process p[20], temp;
    float avg_wt = 0, avg_tat = 0;

    printf("Enter number of processes: ");
    scanf("%d", &n);

    for (i = 0; i < n; i++) {
        p[i].id = i + 1;
        printf("Burst time and Priority of P%d: ", p[i].id);
        scanf("%d %d", &p[i].bt, &p[i].pr);
    }

    // Sort by priority (ascending -> highest priority first)
    for (i = 0; i < n - 1; i++)
        for (j = 0; j < n - i - 1; j++)
            if (p[j].pr > p[j + 1].pr) {
                temp = p[j];
                p[j] = p[j + 1];
                p[j + 1] = temp;
            }

    p[0].wt = 0;
    for (i = 1; i < n; i++)
        p[i].wt = p[i - 1].wt + p[i - 1].bt;

    for (i = 0; i < n; i++) {
        p[i].tat = p[i].wt + p[i].bt;
        avg_wt += p[i].wt;
        avg_tat += p[i].tat;
    }

    printf("\nProcess\tBurst\tPriority\tWaiting\tTurnaround\n");
    for (i = 0; i < n; i++)
        printf("P%d\t%d\t%d\t\t%d\t%d\n", p[i].id, p[i].bt, p[i].pr, p[i].wt, p[i].tat);

    printf("\nAverage Waiting Time    = %.2f\n", avg_wt / n);
    printf("Average Turnaround Time = %.2f\n", avg_tat / n);
    return 0;
}

----------------------------------------------------------------------
