EXPERIMENT 31 — FIFO Page Replacement
======================================================================

AIM:
To simulate the First In First Out (FIFO) paging technique of memory management using C.

ALGORITHM:
1. Read the reference string and number of frames.
2. Maintain a queue representing frames in the order they were loaded.
3. For each page reference: if it is already in a frame, it's a hit; otherwise it's a fault — if frames are full, remove the page at the front of the queue (oldest) and insert the new page at the back.
4. Count total page faults.
5. Display the frame status after each reference and the total faults.
6. Stop.

PROGRAM (copy-paste ready):
----------------------------------------------------------------------
#include <stdio.h>

int main() {
    int pages[50], n, frames[10], nf;
    int front = 0, faults = 0, filled = 0;

    printf("Enter number of pages: ");
    scanf("%d", &n);
    printf("Enter reference string: ");
    for (int i = 0; i < n; i++) scanf("%d", &pages[i]);

    printf("Enter number of frames: ");
    scanf("%d", &nf);
    for (int i = 0; i < nf; i++) frames[i] = -1;

    for (int i = 0; i < n; i++) {
        int found = 0;
        for (int j = 0; j < nf; j++)
            if (frames[j] == pages[i]) { found = 1; break; }

        if (!found) {
            frames[front] = pages[i];
            front = (front + 1) % nf;
            faults++;
        }

        printf("Ref %d -> Frames: ", pages[i]);
        for (int j = 0; j < nf; j++)
            (frames[j] == -1) ? printf("- ") : printf("%d ", frames[j]);
        printf(found ? "(hit)\n" : "(fault)\n");
    }

    printf("\nTotal Page Faults = %d\n", faults);
    return 0;
}

----------------------------------------------------------------------

Enter reference string: 7 0 1 2 0 3 0 4 2
Enter number of frames: 3

SAMPLE OUTPUT:
