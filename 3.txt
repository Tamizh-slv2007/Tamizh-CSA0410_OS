EXPERIMENT 3 — FCFS CPU Scheduling
======================================================================

AIM:
To design a CPU scheduling program using the First Come First Served (FCFS) technique, assuming all processes arrive at time 0 and none wait on I/O.

ALGORITHM:
1. Start the program.
2. Read number of processes `n` and their burst times.
3. Process 0's waiting time = 0.
4. For each process i (i>0): waiting time[i] = waiting time[i-1] + burst time[i-1].
5. Turnaround time[i] = waiting time[i] + burst time[i].
6. Compute average waiting time and average turnaround time.
7. Display the Gantt chart order, waiting and turnaround times.
8. Stop.

PROGRAM (copy-paste ready):
----------------------------------------------------------------------
#include <stdio.h>

int main() {
    int n, i;
    int bt[20], wt[20], tat[20];
    float avg_wt = 0, avg_tat = 0;

    printf("Enter number of processes: ");
    scanf("%d", &n);

    printf("Enter burst time for each process:\n");
    for (i = 0; i < n; i++) {
        printf("P%d: ", i + 1);
        scanf("%d", &bt[i]);
    }

    wt[0] = 0;
    for (i = 1; i < n; i++)
        wt[i] = wt[i - 1] + bt[i - 1];

    for (i = 0; i < n; i++) {
        tat[i] = wt[i] + bt[i];
        avg_wt += wt[i];
        avg_tat += tat[i];
    }

    printf("\nProcess\tBurst\tWaiting\tTurnaround\n");
    for (i = 0; i < n; i++)
        printf("P%d\t%d\t%d\t%d\n", i + 1, bt[i], wt[i], tat[i]);

    printf("\nAverage Waiting Time    = %.2f\n", avg_wt / n);
    printf("Average Turnaround Time = %.2f\n", avg_tat / n);
    return 0;
}

----------------------------------------------------------------------

SAMPLE INPUT VALUE(S):
Enter number of processes: 4
P1: 5
P2: 3
P3: 8
P4: 6

SAMPLE OUTPUT:
