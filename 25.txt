EXPERIMENT 25 — I/O System Calls (fcntl, lseek, stat, opendir, readdir)
======================================================================

AIM:
To implement the I/O system calls of UNIX — `fcntl`, `lseek`, `stat`, `opendir`, `readdir` — using a C program.

ALGORITHM:
1. Open a file and use `fcntl()` to retrieve/modify its file access flags.
2. Use `lseek()` to move the file offset and confirm the new position.
3. Use `stat()` to retrieve and display file metadata (size, permissions).
4. Use `opendir()` and `readdir()` to list the entries of the current directory.
5. Close all open handles.
6. Stop.

PROGRAM (copy-paste ready):
----------------------------------------------------------------------
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <dirent.h>

int main() {
    int fd = open("demo.txt", O_CREAT | O_RDWR | O_TRUNC, 0644);
    write(fd, "OS Lab IO system calls demo", 28);

    // fcntl
    int flags = fcntl(fd, F_GETFL);
    printf("File access flags (fcntl) = %d\n", flags);

    // lseek
    off_t pos = lseek(fd, 5, SEEK_SET);
    printf("New file offset (lseek) = %ld\n", (long) pos);
    close(fd);

    // stat
    struct stat st;
    stat("demo.txt", &st);
    printf("\nFile size (stat) = %ld bytes\n", (long) st.st_size);
    printf("File permissions = %o\n", st.st_mode & 0777);

    // opendir / readdir
    printf("\nCurrent directory listing:\n");
    DIR *dir = opendir(".");
    struct dirent *entry;
    while ((entry = readdir(dir)) != NULL)
        printf("  %s\n", entry->d_name);
    closedir(dir);

    unlink("demo.txt");
    return 0;
}
