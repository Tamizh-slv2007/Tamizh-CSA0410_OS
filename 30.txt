EXPERIMENT 30 — Thread Concepts: create, join, equal, exit
======================================================================

AIM:
To demonstrate thread-related concepts — `pthread_create`, `pthread_join`, `pthread_equal`, and `pthread_exit` — using C programs.

ALGORITHM:
1. **create:** use `pthread_create()` to spawn a new thread running a given function.
2. **join:** use `pthread_join()` in the main thread to wait for a child thread to finish and optionally retrieve its return value.
3. **equal:** use `pthread_equal()` to compare two thread IDs and check whether they refer to the same thread.
4. **exit:** use `pthread_exit()` inside a thread function to terminate that thread and optionally pass back a result.
5. Stop.

PROGRAM (copy-paste ready):
----------------------------------------------------------------------
#include <stdio.h>
#include <pthread.h>

pthread_t t1, t2;

void *worker(void *arg) {
    int id = *(int *) arg;
    printf("Thread %d started (ID = %lu)\n", id, pthread_self());

    if (pthread_equal(pthread_self(), t1))
        printf("Thread %d is Thread-1\n", id);
    else
        printf("Thread %d is Thread-2\n", id);

    pthread_exit((void *) "Thread finished successfully");
}

int main() {
    int id1 = 1, id2 = 2;
    void *result;

    // create
    pthread_create(&t1, NULL, worker, &id1);
    pthread_create(&t2, NULL, worker, &id2);

    // equal
    if (pthread_equal(t1, t2))
        printf("t1 and t2 are the same thread.\n");
    else
        printf("t1 and t2 are different threads.\n");

    // join
    pthread_join(t1, &result);
    printf("Thread-1 returned: %s\n", (char *) result);

    pthread_join(t2, &result);
    printf("Thread-2 returned: %s\n", (char *) result);

    return 0;
}
