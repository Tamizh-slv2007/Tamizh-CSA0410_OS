EXPERIMENT 32 — LRU Page Replacement
======================================================================

AIM:
To simulate the Least Recently Used (LRU) paging technique of memory management using C.

ALGORITHM:
1. Read the reference string and number of frames.
2. For each page reference, check if the page is already present in the frames (hit).
3. If not present (fault): if there is a free frame, place the page there; otherwise replace the page whose most recent use is farthest in the past.
4. Update the "last used" time for the referenced page after every access.
5. Count total page faults and display frame contents after each step.
6. Stop.

PROGRAM (copy-paste ready):
----------------------------------------------------------------------
#include <stdio.h>
#include <limits.h>

int main() {
    int pages[50], n, frames[10], nf, lastUsed[10];
    int faults = 0, time = 0;

    printf("Enter number of pages: ");
    scanf("%d", &n);
    printf("Enter reference string: ");
    for (int i = 0; i < n; i++) scanf("%d", &pages[i]);

    printf("Enter number of frames: ");
    scanf("%d", &nf);
    for (int i = 0; i < nf; i++) { frames[i] = -1; lastUsed[i] = -1; }

    for (int i = 0; i < n; i++) {
        int found = -1;
        for (int j = 0; j < nf; j++)
            if (frames[j] == pages[i]) { found = j; break; }

        if (found != -1) {
            lastUsed[found] = time;
        } else {
            int replaceIdx = -1;
            for (int j = 0; j < nf; j++)
                if (frames[j] == -1) { replaceIdx = j; break; }

            if (replaceIdx == -1) {
                int minTime = INT_MAX;
                for (int j = 0; j < nf; j++)
                    if (lastUsed[j] < minTime) { minTime = lastUsed[j]; replaceIdx = j; }
            }

            frames[replaceIdx] = pages[i];
            lastUsed[replaceIdx] = time;
            faults++;
        }

        printf("Ref %d -> Frames: ", pages[i]);
        for (int j = 0; j < nf; j++)
            (frames[j] == -1) ? printf("- ") : printf("%d ", frames[j]);
        printf(found != -1 ? "(hit)\n" : "(fault)\n");

        time++;
    }

    printf("\nTotal Page Faults = %d\n", faults);
    return 0;
}

----------------------------------------------------------------------

Enter reference string: 7 0 1 2 0 3 0 4 2
Enter number of frames: 3
