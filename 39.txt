EXPERIMENT 39 — C-SCAN Disk Scheduling
======================================================================

AIM:
To simulate the C-SCAN (Circular SCAN) disk scheduling algorithm using C.

ALGORITHM:
1. Read the disk request queue, initial head position and disk size (movement assumed toward the higher end).
2. Sort the requests.
3. Service all requests from the head position up to the highest cylinder (disk size − 1).
4. Jump directly to cylinder 0 (this jump is *not* counted as head movement, only as a seek) and then service the remaining requests below the initial head, moving upward again.
5. Sum head movements for all serviced steps.
6. Display the seek sequence and total head movement.
7. Stop.

PROGRAM (copy-paste ready):
----------------------------------------------------------------------
#include <stdio.h>
#include <stdlib.h>

int cmp(const void *a, const void *b) { return (*(int *) a - *(int *) b); }

int main() {
    int n, head, diskSize, total = 0;
    int req[100];

    printf("Enter number of requests: ");
    scanf("%d", &n);
    printf("Enter the requests:\n");
    for (int i = 0; i < n; i++) scanf("%d", &req[i]);

    printf("Enter initial head position: ");
    scanf("%d", &head);
    printf("Enter disk size: ");
    scanf("%d", &diskSize);

    qsort(req, n, sizeof(int), cmp);

    int left[100], right[100], li = 0, ri = 0;
    for (int i = 0; i < n; i++) {
        if (req[i] < head) left[li++] = req[i];
        else right[ri++] = req[i];
    }

    printf("\nSeek Sequence: %d", head);

    for (int i = 0; i < ri; i++) { total += abs(right[i] - head); head = right[i]; printf(" -> %d", head); }

    total += abs((diskSize - 1) - head);
    printf(" -> %d", diskSize - 1);

    // jump to 0 (not counted)
    printf(" -> 0");
    head = 0;

    for (int i = 0; i < li; i++) { total += abs(left[i] - head); head = left[i]; printf(" -> %d", head); }

    printf("\n\nTotal Head Movement = %d\n", total);
    return 0;
}

----------------------------------------------------------------------

SAMPLE INPUT VALUE(S):
Enter number of requests: 8
Enter the requests: 98 183 37 122 14 124 65 67
Enter initial head position: 53
Enter disk size: 200

SAMPLE OUTPUT:
Seek Sequence: 53 -> 65 -> 67 -> 98 -> 122 -> 124 -> 183 -> 199 -> 0 -> 14 -> 37

Total Head Movement = 382
