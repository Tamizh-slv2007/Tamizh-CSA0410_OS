EXPERIMENT 24 — UNIX System Calls for File Management
======================================================================

AIM:
To demonstrate UNIX system calls used for file management (create, open, read, write, close, unlink) using a C program.

ALGORITHM:
1. Create a file using `creat()` or `open()` with `O_CREAT`.
2. Write data into the file using `write()`.
3. Close the file using `close()`.
4. Reopen the file, read its contents using `read()`, and display them.
5. Delete the file using `unlink()`.
6. Stop.

PROGRAM (copy-paste ready):
----------------------------------------------------------------------
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>
#include <string.h>

int main() {
    int fd;
    char data[] = "File management using UNIX system calls.";
    char buffer[100];

    // Create and write
    fd = open("demo.txt", O_CREAT | O_WRONLY | O_TRUNC, 0644);
    write(fd, data, strlen(data));
    close(fd);
    printf("File created and written.\n");

    // Read back
    fd = open("demo.txt", O_RDONLY);
    int n = read(fd, buffer, sizeof(buffer) - 1);
    buffer[n] = '\0';
    close(fd);
    printf("File contents: %s\n", buffer);

    // Delete
    if (unlink("demo.txt") == 0)
        printf("File deleted successfully.\n");
    else
        perror("unlink");

    return 0;
}
