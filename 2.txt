EXPERIMENT 2 — File Copy using System Calls
======================================================================

AIM:
To identify the system calls used to copy the contents of one file to another and to illustrate the same using a C program.

ALGORITHM:
1. Start the program.
2. Open the source file in read-only mode using `open()`.
3. Create/open the destination file in write mode using `open()`.
4. Read data from source file into a buffer using `read()`.
5. Write the buffer contents into the destination file using `write()`.
6. Repeat steps 4–5 until end of file is reached.
7. Close both files using `close()`.
8. Stop.

PROGRAM (copy-paste ready):
----------------------------------------------------------------------
#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>

#define BUF_SIZE 1024

int main(int argc, char *argv[]) {
    int src_fd, dst_fd;
    ssize_t n;
    char buffer[BUF_SIZE];
    char srcname[100], dstname[100];

    printf("Enter source file name: ");
    scanf("%s", srcname);
    printf("Enter destination file name: ");
    scanf("%s", dstname);

    src_fd = open(srcname, O_RDONLY);
    if (src_fd < 0) {
        perror("open source");
        exit(1);
    }

    dst_fd = open(dstname, O_WRONLY | O_CREAT | O_TRUNC, 0644);
    if (dst_fd < 0) {
        perror("open destination");
        exit(1);
    }

    while ((n = read(src_fd, buffer, BUF_SIZE)) > 0) {
        write(dst_fd, buffer, n);
    }

    close(src_fd);
    close(dst_fd);

    printf("File copied successfully.\n");
    return 0;
}
