EXPERIMENT 7 — Non-Preemptive SJF Scheduling (with Arrival Times)
======================================================================

AIM:
To implement the non-preemptive Shortest Job First (SJF) scheduling algorithm, considering different arrival times for processes.

ALGORITHM:
1. Start the program.
2. Read `n` processes with arrival time and burst time.
3. At each scheduling point, among all processes that have arrived and not yet executed, pick the one with the smallest burst time.
4. Execute it fully (non-preemptive); update completion, turnaround and waiting times.
5. Repeat until all processes are scheduled.
6. Compute and display averages.
7. Stop.

PROGRAM (copy-paste ready):
----------------------------------------------------------------------
#include <stdio.h>
#define MAX 20

int main() {
    int n, i, at[MAX], bt[MAX], done[MAX] = {0};
    int ct[MAX], tat[MAX], wt[MAX];
    int completed = 0, time = 0, idx;
    float avg_wt = 0, avg_tat = 0;

    printf("Enter number of processes: ");
    scanf("%d", &n);

    for (i = 0; i < n; i++) {
        printf("Arrival and Burst time of P%d: ", i + 1);
        scanf("%d %d", &at[i], &bt[i]);
    }

    while (completed != n) {
        idx = -1;
        int min_bt = 9999;
        for (i = 0; i < n; i++) {
            if (!done[i] && at[i] <= time && bt[i] < min_bt) {
                min_bt = bt[i];
                idx = i;
            }
        }
        if (idx == -1) {
            time++;
            continue;
        }
        time += bt[idx];
        ct[idx] = time;
        tat[idx] = ct[idx] - at[idx];
        wt[idx] = tat[idx] - bt[idx];
        done[idx] = 1;
        completed++;
    }

    printf("\nProcess\tArrival\tBurst\tCompletion\tTurnaround\tWaiting\n");
    for (i = 0; i < n; i++) {
        printf("P%d\t%d\t%d\t%d\t\t%d\t\t%d\n", i + 1, at[i], bt[i], ct[i], tat[i], wt[i]);
        avg_wt += wt[i];
        avg_tat += tat[i];
    }

    printf("\nAverage Waiting Time    = %.2f\n", avg_wt / n);
    printf("Average Turnaround Time = %.2f\n", avg_tat / n);
    return 0;
}
