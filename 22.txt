EXPERIMENT 22 — Best Fit Memory Allocation
======================================================================

AIM:
To implement the best fit algorithm of memory management using C.

ALGORITHM:
1. Read block sizes and process sizes.
2. For each process, scan all free blocks with size ≥ process size and choose the **smallest** among them (minimizes leftover fragmentation).
3. Allocate the process to that block and reduce the block's available size.
4. If no block is large enough, mark the process as not allocated.
5. Display the allocation table.
6. Stop.

PROGRAM (copy-paste ready):
----------------------------------------------------------------------
#include <stdio.h>

int main() {
    int m, n;
    printf("Enter number of blocks: ");
    scanf("%d", &m);
    int block[20];
    printf("Enter block sizes: ");
    for (int i = 0; i < m; i++) scanf("%d", &block[i]);

    printf("Enter number of processes: ");
    scanf("%d", &n);
    int process[20], allocation[20];
    printf("Enter process sizes: ");
    for (int i = 0; i < n; i++) { scanf("%d", &process[i]); allocation[i] = -1; }

    for (int i = 0; i < n; i++) {
        int bestIdx = -1;
        for (int j = 0; j < m; j++)
            if (block[j] >= process[i])
                if (bestIdx == -1 || block[j] < block[bestIdx])
                    bestIdx = j;
        if (bestIdx != -1) {
            allocation[i] = bestIdx;
            block[bestIdx] -= process[i];
        }
    }

    printf("\nProcess No.\tProcess Size\tBlock No.\n");
    for (int i = 0; i < n; i++) {
        if (allocation[i] != -1)
            printf("P%d\t\t%d\t\t%d\n", i + 1, process[i], allocation[i] + 1);
        else
            printf("P%d\t\t%d\t\tNot Allocated\n", i + 1, process[i]);
    }
    return 0;
}

----------------------------------------------------------------------

Enter block sizes: 100 500 200 300
Enter number of processes: 3
Enter process sizes: 90 250 100
