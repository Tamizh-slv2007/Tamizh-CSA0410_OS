EXPERIMENT 12 — Dining Philosophers Problem
======================================================================

AIM:
To simulate the Dining Philosophers problem using C, avoiding deadlock.

ALGORITHM:
1. Represent each fork as a mutex/semaphore; there are `n` philosophers and `n` forks.
2. Each philosopher thread alternates between thinking and eating.
3. To avoid deadlock, an odd philosopher picks up the left fork first then the right, while an even philosopher picks up the right fork first then the left (breaking the circular wait).
4. After eating, the philosopher releases both forks.
5. Repeat for a fixed number of cycles.
6. Stop.

PROGRAM (copy-paste ready):
----------------------------------------------------------------------
#include <stdio.h>
#include <pthread.h>
#include <semaphore.h>
#include <unistd.h>

#define N 5

sem_t forks[N];
pthread_t philosophers[N];

void *philosopher(void *num) {
    int id = *(int *) num;
    int left = id;
    int right = (id + 1) % N;

    for (int cycle = 0; cycle < 2; cycle++) {
        printf("Philosopher %d is thinking\n", id);
        sleep(1);

        if (id % 2 == 0) {          // even: right fork first
            sem_wait(&forks[right]);
            sem_wait(&forks[left]);
        } else {                    // odd: left fork first
            sem_wait(&forks[left]);
            sem_wait(&forks[right]);
        }

        printf("Philosopher %d is eating\n", id);
        sleep(1);

        sem_post(&forks[left]);
        sem_post(&forks[right]);
    }
    return NULL;
}

int main() {
    int ids[N];
    for (int i = 0; i < N; i++) {
        sem_init(&forks[i], 0, 1);
        ids[i] = i;
    }
    for (int i = 0; i < N; i++)
        pthread_create(&philosophers[i], NULL, philosopher, &ids[i]);
    for (int i = 0; i < N; i++)
        pthread_join(philosophers[i], NULL);

    printf("Simulation complete. No deadlock occurred.\n");
    return 0;
}
